# Брейнрот Раш

Браузерный раннер. Уворачивайся от ловушек, собирай чипы и открывай брейнротов.

## Запуск

Открой `dist/index.html` в браузере. На компьютере меняй дорожки стрелками или A и D, а для рывка нажимай пробел. На телефоне используй экранные кнопки или свайп.

## Яндекс Игры

Упакуй содержимое `dist` в ZIP так, чтобы `index.html` был в корне. Загрузи архив в черновик Консоли Яндекс Игр. Текст для карточки лежит в `catalog/card-ru.txt`. В черновике можно проверить SDK и добровольную рекламу за удвоение чипов.

[Инструкция Яндекс Игр](https://yandex.ru/dev/games/doc/ru/console/add-new-game)
